# Akshay Computers — Official Brand Assets

Identity v2 (premium maroon, July 2026). The **SVG files are the vector
masters** — they stay perfectly sharp at any size (website, business cards,
banners, invoices, signboards). PNGs are convenience exports.

## Files

| File | What it is | Use on |
|---|---|---|
| `akshay-icon.svg` | Icon, maroon gradient (MASTER) | Light backgrounds |
| `akshay-icon-mono.svg` | Icon, solid maroon `#8B1E1E` | Single-color print, stamps |
| `akshay-icon-white.svg` | Icon, solid white | Dark backgrounds |
| `akshay-watermark.svg` | Icon at 6% opacity, monochrome | Document/quotation/invoice backgrounds |
| `akshay-logo-horizontal.svg` | Icon + name, one line | Website header, email signatures |
| `akshay-logo-full.svg` | Icon + name + tagline, stacked | Covers, presentations, social profiles |
| `akshay-icon-1024.png` | 1024px transparent PNG | WhatsApp Business, social avatars |
| `akshay-icon-mono-1024.png` | 1024px mono PNG | — |
| `akshay-icon-white-1024.png` | 1024px white PNG | Dark backgrounds |
| `akshay-logo-horizontal-2000.png` | 2000px horizontal lockup | Letterheads, banners |
| `akshay-logo-full-1400.png` | 1400px full lockup | Print, presentations |

## Colors

Deep Maroon `#8B1E1E` (primary) · Dark Red `#A52A2A` · Soft Crimson `#C0392B`
Text: Charcoal `#2C2C2C` · Tagline gray `#4A4A4A`

## Typography

Brand name: **Playfair Display Bold** (Georgia as system fallback — the PNG
exports use Georgia). Tagline: letter-spaced caps.
"Akshay" in charcoal, "Computers" in maroon (white/rose on dark surfaces).

## Notes

- **PDF versions:** any print shop or design tool (Illustrator, Inkscape,
  even the browser's print-to-PDF) converts the SVG masters to PDF losslessly.
- The horizontal/full **SVG** lockups reference the Playfair Display font by
  name — on machines without it they fall back to Georgia. For guaranteed
  identical output in professional printing, use the PNG exports or convert
  text to outlines in a design tool once.
- Favicon is generated from the same geometry (`src/app/icon.svg`).
